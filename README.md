# Vocal Trainer

Тренажёр для пения в браузере телефона: упражнения с подсказкой-пианино, нотный стан,
разбор интонации по микрофону, хоровые партии (сопрано, альт, тенор, бас).

**Открыть:** https://pogrommer.github.io/vocal-trainer/

Установить как приложение:
- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открыть в Chrome → меню ⋮ → «Установить приложение».

После первого открытия работает без интернета: упражнения всегда, песня — последняя открытая.
Пойте в наушниках, иначе микрофон слышит подсказку.
